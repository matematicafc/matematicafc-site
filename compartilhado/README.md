# Recursos compartilhados

Reservar esta área para arquivos efetivamente reutilizados por mais de um recurso:

- `css/`: estilos comuns, sempre restritos aos contêineres do projeto.
- `js/`: utilitários e comportamento compartilhado, sem variáveis globais desnecessárias.
- `imagens/`: ilustrações reutilizáveis, com origem, licença e descrição documentadas.

As subpastas serão criadas quando houver arquivos para elas. Não antecipar uma
biblioteca ou adicionar dependências nesta etapa. Arquivos específicos devem
permanecer na pasta do respectivo recurso.

Ao reutilizar arquivos, documentar versão, consumidores, forma de carregamento
e hospedagem para o Blogger. Nenhum recurso compartilhado foi implementado ainda.
