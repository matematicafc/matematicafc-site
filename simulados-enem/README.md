# Simulados ENEM

Área para simulados com questões originais de Matemática no estilo ENEM,
contextualizadas e acompanhadas de resolução comentada.

Seguir as [regras dos simulados e boletins](../docs/simulados.md), incluindo
recursos visuais relevantes em pelo menos 50% das questões de cada tentativa,
nome opcional e resultados processados localmente, com PDF e compartilhamento
voluntário pelo estudante.

Cada simulado deverá documentar objetivos, conteúdos e fontes oficiais de
referência. Planejar navegação entre questões, preservação das respostas,
indicação de progresso, tratamento de questões não respondidas e gabarito
comentado ao final. Eventuais estimativas de desempenho não devem ser apresentadas
como nota oficial do ENEM ou resultado da TRI sem metodologia válida.

Criar uma pasta por simulado conforme as
[convenções de desenvolvimento](../docs/desenvolvimento.md).
Esta área ainda não contém questões ou simulados implementados.
