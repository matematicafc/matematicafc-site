# Melhorias das postagens

Área para gráficos, animações, explicações matemáticas, recursos visuais e
aperfeiçoamentos de layout destinados às postagens do MatemáticaFC.

Criar uma pasta por melhoria e registrar a postagem de destino, o objetivo
pedagógico, o comportamento esperado e as instruções de integração. Fornecer
alternativas textuais para gráficos e ilustrações; animações deverão ter controles
adequados e respeitar a preferência por movimento reduzido.

Restringir alterações de layout ao recurso para evitar interferência no tema.
Seguir as [convenções de desenvolvimento](../docs/desenvolvimento.md) e as
[orientações para o Blogger](../docs/blogger.md).
Esta área ainda não contém melhorias implementadas.
